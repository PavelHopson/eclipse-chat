# Eclipse Chat → DnD Forge: разделение AI-поверхности

## Решение

Eclipse Chat остаётся коммуникационной и operational-поверхностью: комнаты,
личные сообщения, voice/video, задачи и контекстные AI-помощники. AI Office,
творческие агентные сценарии и офисная навигация переходят в Eclipse DnD Forge.

## Что видит пользователь

- В основной desktop- и mobile-навигации Chat больше нет пункта «AI-офис».
- Подключение к DnD Forge уже доступно в настройках → «Интеграции».
- Существующая ссылка «DnD Forge» в меню пользователя остаётся единой точкой
  перехода к кампании, картам и AI-сценариям.

## Обратимость и границы

Legacy Agent Office, его runtime и данные не удаляются. Временный rollback или
миграционный доступ включается только явным `VITE_CHAT_AI_OFFICE_ENABLED=1`.
Без этого флага `openAgentOffice` не открывает поверхность даже при старом
внутреннем вызове.

Backend, permissions, approvals, audit и база данных этим изменением не
затронуты. Prisma migration не требуется. Никакие AI-ключи не переносятся в
клиент и не добавляются в сборку.
