# Eclipse Chat v1.7.65 — conversation workspace

Production publication approved by the user on 2026-08-28. Target: the existing
master branch and https://app.star-crm.ru/eclipse-chat/. Release is pending
verification and deployment; this document does not assert production success.

## Scope

- Message-to-task flow: explicit creation, quiet source-aware forms and details,
  preserved assignment, due dates, approvals, dependencies, comments and history.
- Conversation composer: autogrow, retained text/files on failure, explicit retry,
  duplicate-submit guard, preserved commands/mentions/voice/upload limits.
- Compact message actions, natural media proportions, searchable task list and
  preserved kanban. Existing logout behavior and authorization remain unchanged.
- Real discussion panel with mobile overlay, collapsible source, attachments,
  HTTP/socket acknowledgement reconciliation and draft-preserving retry.
- Search result preview and return to the prior reading location; separate unread,
  mention and new-discussion-reply signals.
- Layout-only focus mode, persisted discussion width, clear connection/loading/
  empty/error states and reduced-motion support.
- Version 1.7.65 in root/web/server manifests, lockfile and service-worker cache.
  The server already reads its manifest; no new version hardcode is introduced.

## Isolation and safety

App.tsx's local preview route, WorkspacePreviewPage, preview transport/fixtures/
styles, .codex-qa files, screenshots, logs, logo research and unrelated dirty
files are excluded from this commit. UI contracts depend on production source,
not local preview files. Production retains the existing authentication entry.

No database migrations, permissions, auth endpoints, DNS, host settings or
secret changes. No new dependencies. CI/deploy changes only add the UI contracts.
Existing immutable action pins and the production approval gate stay intact.

Use the documented workflow: validate locally and in CI, wait for CI and Security
Gate, then approve only the exact release run. The production preflight verifies
root-only custom-format backups of eclipse_chat and star_crm_prod before changing
the managed checkout. Existing staged-build rollback remains enabled. Star CRM is
checked for availability; StarMarket is outside this release.
