## Scope

- Refined local audio/video players, seek/buffer/speed/volume controls, bounded
  feedback, error/retry states, fullscreen and fit/100% media views.
- Shared player Queue/Library views, readable labels, server-anchored timing,
  role-aware queue editing with positional duplicates and concurrency protection.
- Quick input/output menus, compact audio participants, retained responsive chat
  widths, clean message identity, viewport-safe overlays and profile refinement.
- Local action sounds with independent volume/mute, Eclipse state transitions,
  reduced-motion preference and hidden-page suspension; no new dependencies.
- Deferral of microphone reconfiguration while muted/deafened/PTT, scoped PWA
  cache cleanup and no production service-worker registration in development.
- Existing tasks, logout, attachment validation and native capabilities retained.
- New media/interaction regressions now run in both CI and deploy validate.
