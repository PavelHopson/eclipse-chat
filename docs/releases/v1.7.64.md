Release approved by the user on 2026-08-27. Target: existing master branch and the
production environment at https://app.star-crm.ru/eclipse-chat/.

- Eclipse pointer for fine mouse input; native text/media cursors and reduced-motion fallback.
- Single-surface profile/logout/search controls; existing logout callback and animation preserved.
- Phosphor regular icons with all 30 existing ec:* channel IDs preserved.

- One active rail surface; no clipped outer selection glow.

## Release isolation

The local App.tsx preview route, WorkspacePreviewPage, preview fixtures/styles,
.codex-qa media, screenshots, logs and unrelated dirty files are not part of this
release commit. Production uses the existing authentication entry point.
The UI contract suite does not depend on any local preview file.

## Safety and deployment

The existing production environment approval stays required. CI now runs the UI
and release contracts in addition to existing server/typecheck/audit gates.
Before the existing checkout/build activation, the production SSH job creates
root-only, uniquely named custom-format PostgreSQL backups of eclipse_chat and
star_crm, as required by DEPLOY-TO-STAR-CRM.md. Both must pass pg_restore --list.
The backup step checks the managed path, available memory and disk space. It does
not delete or rotate backups and does not print credentials or database contents.
An unavailable database, failed dump or failed validation stops the update.

Existing staged-build rollback and Nginx validation remain unchanged. No DNS,
database schema, roles, auth endpoints or production secrets are changed by this
release. Shared-host Star CRM receives only the documented read-only DB backup
and a post-deploy availability check; StarMarket is not a deployment target.
