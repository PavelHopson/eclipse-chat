# Eclipse Chat v1.7.66 — voice workspace and release hardening

User authorized the security fixes and production rollout on 2026-08-28.
Target: existing master, https://app.star-crm.ru/eclipse-chat/.
This release supersedes the held v1.7.65 deployment, retaining its approved
conversation/task changes and adding the approved voice-room refinement.

## Scope

- One room header/player/join action, persistent call controls, responsive scene,
  selectable/pinned video source, participant filmstrip and resizable room chat.
- Explicit mic check and muted join, local opt-in music ducking, speech corona,
  reduced-motion handling, unread/mention signals and preserved reading position.
- Descriptor-based env reading with no-follow, bounded reads, owner/mode/type/
  hardlink checks, mutation detection and guaranteed descriptor cleanup.
- Unbiased credential generation without changing length, alphabet or stored
  credentials; bot keys keep their existing 32-character base64url payload.
- Random server-generated upload basenames, preserving existing URLs, original
  filename metadata, MIME/size/signature validation and authorization.
- Single-pass link-preview entity decoding; rendering remains escaped React text.
- Both production checkouts require the validated workflow SHA. Existing approval,
  verified database backups and rollback stay intact; env parent ownership is
  checked before changing the checkout.
- Version 1.7.66 in root/web/server manifests, lockfile and service-worker cache.

## Exclusions and verification limits

No local preview routes, fixtures, demo transports, QA scripts assets, research,
logs or unrelated dirty files enter the release. No dependencies, migrations,
credentials, DNS, branch protection or access-control policy changes.
Native installers are not rebuilt by this web/server rollout.

UI evidence: docs/design/voice-room-qa-2026-08-28.md and
docs/design/voice-experience-qa-2026-08-28.md. Local synthetic media QA is not
evidence of a real multi-user WebRTC call or physical-device/native QA.
Security disposition: docs/security/v1.7.66-release-security.md.
