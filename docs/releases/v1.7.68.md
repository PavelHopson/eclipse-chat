# Eclipse Chat v1.7.68 — unified motion and multi-account sessions

Release authorized by the user on 2026-08-30.
Target: existing `master`, https://app.star-crm.ru/eclipse-chat/.
Status: production verified on 2026-08-30 at 14:10 UTC.

## Scope

- Added an autonomous Eclipse logo/corona cycle and clearer hover/focus gestures
  for the established icon family. Motion respects the quiet setting and
  `prefers-reduced-motion`.
- Refined the semantic Eclipse cursor and unified workspace/settings surfaces in
  dark and light themes without changing the existing task, logout or profile
  flows.
- Added local multi-account management: add, switch and remove remembered
  accounts from the status menu and settings.
- Changed ordinary login/logout session semantics so another browser or desktop
  session is not revoked. Password change/recovery keep the intentional global
  revocation behavior.
- Added session-isolation and UI-unification regressions to the release contracts.
