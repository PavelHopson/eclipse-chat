# Eclipse Chat: сообщение → задача

Дата: 2026-08-28. Статус: локально, не опубликовано. Production остаётся v1.7.64.

## Границы изменения

The Taste применён к рабочему интерфейсу: компактная форма вместо набора равнозначных карточек, один основной золотой акцент, раскрываемые второстепенные поля. Шрифты и бренд Eclipse сохранены. Маркетинговых эффектов в переписку не добавлено.

Название связанной задачи теперь открывает детали. Завершение — отдельная кнопка с состоянием, защитой от повторного запроса и ошибкой без потери данных. Задача, решение, контроль, риск и требование остаются доступными.

На desktop детали занимают правую колонку и не блокируют чат. На mobile это диалог с удержанием фокуса, Escape и возвратом фокуса. Согласования, зависимости, память, AI-сводка, комментарии и история не удалены. Переход «к сообщению» использует существующую загрузку точного источника. Открытие треда возвращает панель треда.

Существующие изменения App.tsx, design-qa.md и DEV preview не перезаписывались. Превью расширено настоящими MessageList, MessageActionModal, ActionItemDrawer с отдельными демоданными. Его API-заглушка работает только в DEV на loopback, не перенаправляет запросы к production; неизвестные операции запрещены.

## Security / ограничения

Новых Critical/High/Medium/Low находок в изменённом сценарии не выявлено. Сохранены JWT, channel membership, TASK_CREATE/TASK_ASSIGN, проверка участника-исполнителя, удалённых сообщений, валидация и rate limit на сервере. Клиент не отправляет скрытое назначение без разрешения. HTML из сообщений не исполняется; новых секретов, внешних ресурсов, зависимостей и storage-механизмов нет.

Это не проверка авторизованного production-сеанса: реальные задачи и пользовательские данные не изменялись. Интеграция настоящего AppShell проверена TypeScript, контрактами и code review; визуальные сценарии выполнены на реальных компонентах в DEV shell с демоданными.

Блокирующих локальных дефектов в сценарии не осталось. Commit, push и deploy не выполнялись; перед публикацией нужны просмотр пользователем и отдельное разрешение.
